Panel Data Website

Cara pakai
  1. Ubah teks, tambah foto karya, atau ganti foto produk. Semua perubahan tersimpan otomatis sebagai draf.
  2. Klik 👁 Pratinjau untuk melihat hasilnya di website (hanya terlihat oleh kamu).
  3. Klik 🚀 Terbitkan untuk mengirim perubahan + foto ke GitHub sekaligus. Pertama kali, isi token di tab Terbitkan.

Tanpa GitHub? Pakai Unduh data.js lalu ganti file assets/js/data.js secara manual.
