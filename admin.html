Cara pakai
  1. Ubah data di bawah ini. Perubahan tersimpan otomatis sebagai draf di browser ini.
  2. Klik Unduh data.js.
  3. Ganti file assets/js/data.js dengan file hasil unduhan, lalu upload/push ke hosting.

Untuk foto: simpan file foto di assets/img/portfolio/ atau assets/img/products/, lalu tulis nama filenya di kolom "File foto".
